# Portfolio Analytics Tool - Franklin Templeton

## Project Details

### Title
Portfolio Analytics Tool

### Brief
Client request: Continue development and take the Portfolio Analytics Tool from Beta to Production release for Franklin Templeton's financial advisors. The tool needed to enable advisors to generate, analyze, and present portfolio performance with configurable benchmarks and hypothetical scenarios based on historical events. Requirements included maintaining brand alignment, ensuring data accuracy from multiple sources, managing user permissions, and providing comprehensive legal disclosures.

## Consolidated Narrative

As a developer at Two-N, I worked on the Portfolio Analytics Tool (formerly Portfolio Construction Tool) for Franklin Templeton, a web application enabling financial advisors and financial professionals to generate, analyze, and present portfolio performance. When I joined, the tool was already in progress, and I started as a front-end developer writing features and bug fixes. After about six months, I was promoted to Lead Developer and oversaw a comprehensive redesign of the application to align with updated brand guidelines, taking the project from Beta to Production release.

The application's design team created wireframes and worked with Franklin Templeton stakeholders on defining new features. Our team also included a Lead Developer responsible for architectural decisions and technical communications, two front-end developers writing features and fixes, and FinMason as a vendor providing APIs backed by Morningstar data.

My responsibilities evolved significantly with my promotion. As Lead Developer, I managed weekly meetings with technical teams at Franklin Templeton and FinMason as the application underwent user testing, legal review, and automated security audits. I coordinated these efforts to ensure the application was ready for release. I also oversaw the comprehensive redesign to align with Franklin's updated brand guidelines, consulting closely with their design team to ensure the application felt at home in their house style.

We faced several key challenges in the design and development process. For design, we needed to maintain clear visual hierarchy in large portfolios across multiple views and chart types while retaining necessary legal disclosure text. Our solution involved careful and consistent use of color, typeface, and font size throughout the application, along with interactive features like tooltips and interface elements to collapse or expand detailed information and UI hints.

For development, we needed to ensure the accuracy of comparative benchmarks and hypothetical scenarios applied to customized portfolios drawn from multiple data sources, manage customizable display settings for multiple charts and tables, and handle project organization and sharing permissions for individual users. We also needed to collect relevant logs and analytics to ensure application performance, identify favored and underutilized features, and help diagnose issues.

On the technical side, we integrated with financial data providers to ensure accurate and timely data updates, and followed an agile development approach with weekly meetings with technical teams. We coordinated user testing, legal review, and automated security audits to ensure the application was production-ready. These efforts enabled the successful transition from Beta to Production release, making the tool available to Franklin Templeton advisors across the organization.

The final deliverable is a comprehensive web application dashboard that enables Franklin Templeton's portfolio advisors and financial professionals to create and manage custom portfolios with configurable benchmarks and hypothetical scenarios based on historical events. The tool provides accurate analysis and presentation capabilities, supporting data-driven portfolio management decisions.
